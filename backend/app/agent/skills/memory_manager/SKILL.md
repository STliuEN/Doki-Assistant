# 记忆与事项管理

当用户要求记录、提醒、安排待办、查询今日事项、查询复习内容或标记事项完成时，使用本 skill。

- 用户说“提醒我”“记一下”“加入待办”“下周再看”时，创建记忆事项。
- 用户问“今天有什么事”“有哪些待办”“今天要复习什么”时，查询记忆事项。
- 对 `review` 类型使用 `mark_memory_reviewed_tool` 推进下一次复习时间。
- 对非 `review` 类型使用 `complete_memory_tool` 标记完成。
- 用户没有提供明确事项 ID 时，先列出候选事项，请用户确认，不要猜测要操作哪一条。
- 涉及相对日期时，先结合当前时间转换为明确日期再创建或延期事项。
