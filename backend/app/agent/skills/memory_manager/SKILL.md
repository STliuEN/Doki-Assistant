# 事项与备忘管理

当用户要求记录、提醒、安排待办、查询今日事项、管理长期事项或保存普通备忘时，使用本 skill。

- 用户说“提醒我”“记一下”“加入待办”“下周再看”时，创建记忆事项。
- 用户问“今天有什么事”“有哪些待办”“有哪些提醒”“长期事项有哪些”时，查询记忆事项。
- 用户提供明确事项 ID 并询问详情时，获取记忆详情。
- 用户要求修改标题、内容、类型、状态、优先级或时间时，使用更新记忆工具。
- 对 `todo`、`reminder`、`long_term`、`memo` 类型使用完成工具标记完成。
- 用户要求推迟事项时，使用延期工具。
- 用户明确表示不再展示但要保留记录时，归档记忆事项。
- 用户明确要求永久删除时，才删除记忆事项；目标不明确时必须先确认。
- 用户没有提供明确事项 ID 时，先列出候选事项，请用户确认，不要猜测要操作哪一条。
- 涉及相对日期时，先结合当前时间转换为明确日期再创建或延期事项。
- 复习计划、今日复习、生成复习题、标记已复习属于“复习计划”功能，不在本 skill 中处理。
