# 工作包 1 变更记录

日期：2026-08-17

- 新增 `backend/app/utils/knowledge_image_paths.py`，集中处理路径校验、媒体类型和 containment。
- 更新知识库图片单文件接口，移除直接拼接 `md5`/`filename` 的逻辑。
- 更新批量图片接口，改用异步文件读取，过滤非图片文件，并加入 100 个文件、25 MiB 总大小限制。
- 更新图片提取和删除逻辑，使目录创建只发生在写入路径，删除路径复用同一 helper。
- 新增路径穿越、编码路径、符号链接、目录创建和批量大小限制测试。
- 2026-08-18 最终审计补强：在 `extracted_images` 根、用户目录、MD5 目录和图片文件每一级拒绝 symlink；Windows 同时拒绝 junction/reparse directory，避免根内链接跨用户读取或删除。

兼容性说明：合法的现有图片路径继续使用原目录结构；非法或不符合扩展名约束的请求现在返回 400，缺失文件返回 404，超过批量预算返回 413。
