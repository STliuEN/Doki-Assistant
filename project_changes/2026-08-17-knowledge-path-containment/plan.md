# 工作包 1：知识库图片路径 containment

日期：2026-08-17
状态：已完成（最终复核：2026-08-18）
关联记录：同目录 `change-log.md`、`test-record.md`

## 目标

统一知识库图片目录和文件路径解析，确保用户输入不能越过 `data/extracted_images/<user_id>/<md5>/`，同时限制批量图片读取的资源消耗。

## 实施范围

- 新增共享路径 helper，规范化 MD5、用户 ID、图片文件名和扩展名。
- 所有读取、写入和删除路径都经过 `resolve()` 与根目录 containment 校验。
- 根目录、用户目录、MD5 目录和图片文件逐级拒绝 symlink；Windows 同时拒绝 junction/reparse point。
- 读取接口不创建目录；批量读取只处理允许的图片类型，并限制最多 100 个文件、总计 25 MiB。
- 明确拒绝反斜杠、绝对路径、盘符路径和跨用户目录访问。

## 回滚方式

恢复本工作包涉及的五个代码文件，并删除对应测试文件；不修改用户数据目录。回滚前应保留失败测试输出和服务日志。
