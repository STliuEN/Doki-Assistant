# 翻译额外要求输入框计划

## 目标

在实时翻译页面顶部模型选择右侧增加一个输入框，默认留空。用户可以临时输入翻译风格或语气要求，例如：

- 用鲁迅的语气
- 更口语化
- 保持商务礼貌
- 用动漫角色的语气

该内容需要注入到翻译 prompt 中，辅助本次翻译。

## 计划

1. 后端翻译请求增加 `custom_instruction` 字段。
2. 翻译服务在 prompt 前注入用户额外要求。
3. 前端增加 `customInstruction` 状态。
4. 顶部模型选择右侧增加输入框。
5. 整篇翻译和实时对话翻译请求都携带该字段。
6. 空内容时不发送该字段，不影响默认行为。
