# 实时翻译修复计划

## 问题

实时翻译页面点击后没有正常启动，且页面布局需要保持左右双栏。

## 判断

前端开发服务器代理缺少 `/translate/`，导致翻译请求可能没有转发到 FastAPI 后端。

同时，用户希望使用小模型保证实时性，因此需要默认采用“不思考”的快速翻译模式。

## 修复计划

1. 给 Vite 增加 `/translate/` 后端代理。
2. 后端请求结构增加 `fast_mode`。
3. 翻译 prompt 改为中文快速翻译提示词。
4. 默认在 prompt 前追加 `/no_think`。
5. 清理模型输出中的 `<think>` 和推理说明。
6. 重写翻译页中文文案，修复乱码。
7. 桌面端保持左右双栏，手机端才上下布局。
