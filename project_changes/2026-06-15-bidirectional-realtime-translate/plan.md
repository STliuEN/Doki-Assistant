# 双语实时翻译修改计划

## 目标

新增一个“实时翻译”功能，用于双语现场对话：

- 用户选择两种语言，例如中文和日语。
- 输入内容可以混合两种语言。
- 系统逐行判断输入主要属于哪种语言。
- 中文内容翻译成日语，日语内容翻译成中文。
- 输出保持输入顺序，适合实时对话使用。

## 后端计划

1. 在 `backend/app/prompt/` 新增中文提示词文件。
2. 在 `backend/app/config/prompt.yaml` 注册提示词。
3. 新增翻译请求 schema。
4. 新增翻译 service，复用当前模型配置体系：
   - 不传 `model_config_id` 时使用工程 `.env` 默认模型。
   - 传入用户模型配置时使用用户选择的模型。
5. 新增 SSE 路由：
   - `POST /translate/dialogue/stream`

## 前端计划

1. 新增 `实时翻译` 页面。
2. 左侧输入，右侧输出。
3. 顶部选择：
   - 语言 A
   - 语言 B
   - 模型
4. 支持操作：
   - 开始翻译
   - 交换语言
   - 清空
   - 复制结果
   - 保存为笔记
5. 在侧边栏加入“实时翻译”入口。

## 验证计划

1. 后端运行 `uv run python -m compileall app`。
2. 前端对本次新增和改动文件做 TypeScript 局部检查。
3. 记录全量检查中被既有文件阻塞的问题。
