# 实时翻译双模式改造计划

## 目标

实时翻译需要分成两个模式：

1. 整篇翻译模式
   - 保留左右大框。
   - 用户输入整段内容后手动点击开始。
   - 允许模型进行必要的内部思考来保证上下文一致。

2. 实时对话模式
   - 左侧像对话输入区。
   - 用户输入一句话后按 Enter 立即发送。
   - 右侧逐句实时输出翻译结果。
   - 每句话独立请求，允许多句话并发翻译。
   - 默认快速模式，不输出思考。

同时移除顶部功能说明文字。

## 实施计划

- 后端 prompt 增加 `{mode_instruction}`。
- `fast_mode=true` 时使用实时快速翻译规则。
- `fast_mode=false` 时使用整篇翻译规则。
- 前端 `RealtimeTranslate.tsx` 改成标签式双模式。
- 实时对话模式不用 `useSSE` 的全局 loading，改成每句话独立 `fetch` 流式读取。
- 底部按钮根据当前模式显示对应操作。
